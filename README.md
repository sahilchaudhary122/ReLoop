# ReLoop

## Offline-First Digital Platform for Informal E-Waste Collection

ReLoop connects India's informal e-waste collectors to the formal recycling and EPR ecosystem.

## Core Flow

Citizen
→ Pickup Request
→ Collector
→ Collection
→ Collection Batch
→ Aggregator Verification
→ Recycler/Refurbisher
→ Processing
→ EPR Eligibility
→ Brand/PRO Dashboard

## Technology Stack

### Mobile
Flutter + Dart + SQLite

### Web
Next.js + React + TypeScript

### Backend
Python + FastAPI

### Database
PostgreSQL + Supabase

### Storage
Supabase Storage / S3-compatible storage

### Authentication
JWT + RBAC

### Maps
Leaflet + OpenStreetMap

### Notifications
Firebase Cloud Messaging

### Deployment
Vercel + Render/Railway + Supabase
